# ДомТех — сайт магазина бытовой техники

Учебный проект по предмету «Proiectarea și dezvoltarea aplicațiilor Web» (PDAW).

Магазин вымышленный, все цены, адреса и телефоны условные.

## Технологии
- HTML5
- CSS3 (без фреймворков)
- JavaScript (будет добавлен позже)

## Структура
- `index.html` — главная страница
- `style.css` — стили сайта
